Zero-Risk Safety

Never touches drive roots, personal folders (Desktop, Documents, Downloads), or system critical directories. Symbolic links and junctions are blocked.

🎛️

Folder-by-Folder Check

Review every target folder interactively with file counts and sizes before deletion, or prompt for confirmation on every folder with -p.

📊

Live Progress Bars

Dual real-time CLI progress bars tracking scanned targets, deleted files count, formatted bytes freed, ETA, and active file paths.

🌐

Comprehensive Browsers

Cleans Brave (all channels), Chrome, Edge, Arc, Vivaldi, Firefox, Waterfox, Opera. Strictly preserves cookies, history, and logins.

🪟

Windows Update & Logs

Cleans leftover $WINDOWS.~BT, $WINDOWS.~WS, Delivery Optimization, and multi-gigabyte CBS and DISM servicing logs.

⚡

Fast & Lightweight

Scans 20,000+ files in seconds with asynchronous streams. Pre-compiled to modern ESM with strict TypeScript 5.7 typing.

Multi-Layered Safety Guarantees

Built from the ground up to prevent data loss

🚫

Protected Directories

Never touches user profile personal roots (Desktop, Documents, Downloads, Pictures, Videos, Music) or system folders (System32, Program Files).

🔗

Symlink & Junction Guard

Never follows NTFS directory junctions or symbolic links, avoiding recursive traversal and unintended data deletion.

⏱️

Immediate Pre-Delete Re-Check

Right before unlinking, files are verified to ensure they have not been modified after the age cutoff and are still regular files.
